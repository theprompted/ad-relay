Ad Relay

Autonomous image ad generator for Claude Code

Point it at a funnel. Walk away. Come back to a folder of ads.

You give it a landing page URL. It reads the funnel, infers the avatar, selects ad formats from a curated swipe file, writes image briefs, runs every brief through a quality gate, and generates the images — all without you touching it.

The lite version runs 4 legs and generates 5 images. No ad copy, no feed preview. That's the full version.

What it does while you're away

Leg 1 — Concept Selection
Reads your funnel in full. Infers the avatar. Picks the 5 ad formats from the swipe file that best match this specific person and offer.
Leg 2 — Image Briefs
For each selected format, writes a hyper-specific image brief — the scene, the contradiction, what makes someone pause before reading a word.
Leg 3 — Quality Gate
Runs every brief through 3 gates: contradiction check, pause check, stock photo check. Anything that fails gets cut. Only what passes gets generated.
Leg 4 — Image Generation
Generates each approved image via fal.ai. Saves to your output folder. Logs every generation.
Leg 5
Writes Facebook ad copy for every image — primary text, headline, description. Never names the product. Sets up the click, not the sale.
Leg 6
Builds a Facebook feed preview HTML — all ads as realistic feed cards with See More toggle, engagement counts, and CTA buttons. Ready to screenshot and share.

Each leg is a fresh Claude instance with clean context — no baggage from previous legs. That's why the output doesn't degrade. Read more on GitHub →
